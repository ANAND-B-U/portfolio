# 👨‍💻 Anand B - Personal Portfolio

Welcome to my personal portfolio! This is a modern, responsive, and fast web application built to showcase my projects, skills, and professional journey. 

🔗 **Live Demo:** [https://anand-b-u.github.io/portfolio/](https://anand-b-u.github.io/portfolio/)

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Vite
- **Styling:** Tailwind CSS
- **Routing:** React Router DOM
- **Forms:** Web3Forms (for contact form submissions)
- **Deployment:** GitHub Pages (via custom `docs` build)

---

## ✨ Features

- 📱 **Fully Responsive:** Looks great on mobile, tablet, and desktop.
- ⚡ **Blazing Fast:** Built with Vite for optimal performance and instant hot module replacement (HMR).
- 🎨 **Modern UI:** Clean, dark-themed design with smooth transitions and hover effects.
-  **Working Contact Form:** Integrated with Web3Forms to send messages directly to my inbox without a backend.
- 🚀 **Lazy Loading:** Components are lazy-loaded to ensure fast initial page loads.

##  Getting Started

To run this project locally on your machine, follow these steps:

### 1. Clone the repository
bash
git clone https://github.com/ANAND-B-U/portfolio.git
cd portfolio

### 2. Install dependencies

npm install

### 3. Start the development server
npm run dev

Open http://localhost:5173 in your browser to see the result.

## 🌐 Deployment
This portfolio is hosted on GitHub Pages.
The Vite configuration (vite.config.js) is set with base: '/portfolio/' and outDir: 'docs' to ensure assets load correctly from the GitHub Pages subpath.
A CNAME file is included in the public folder to support custom domain routing (if applicable).
